# 我的主队 — Design Spec

## Overview
Add a "My Team" subscription feature to `worldcuppro.html`. Users pick a main team after login, then access a dedicated team page with AI analysis, player info, schedule, and news.

## Architecture
All-in-one: single-file changes to `worldcuppro.html`. No new HTML files. Team page as modal overlay, consistent with existing team page modal style.

## Components

### 1. Team Selection Flow
- After login/register (`onLoginSuccess`): check `profiles.main_team`
- If empty → show team picker modal: searchable dropdown (48 teams + knockout qualifiers), "确认" button, "暂时跳过" link
- Skip → close, nav shows "❤️ 我的主队" (reopens picker)
- Confirm → upsert `profiles.main_team`, nav shows "❤️ [teamName]" (opens my-team page)
- Supabase: `profiles` table gets `main_team` TEXT column

### 2. Navigation
- Not logged in → hide
- Logged in, no team → "❤️ 我的主队" (opens picker)
- Logged in, has team → "❤️ [teamName]" (opens my-team page)

### 3. My Team Page (modal overlay, #myTeamOverlay)
Four card sections:

**📊 AI Analysis Card**
- Framework: `generateStaticAnalysis(teamName)` using internal data (FIFA rank, group, historical best, squad value, group opponents)
- Placeholder for DeepSeek: `getAIAnalysis()` function with TODO comment, ready to swap

**👥 Player Info Card**
- Table: Jersey #, Name (CN preferred), Position, Age, Club, Value
- Name priority: WebSearch Chinese name → TEAM_PLAYER_CN (if rebuilt) → English fallback
- Paged/scrollable if >23 players

**📅 Schedule Card**
- From ALL_MATCHES: filter `m.home===teamName || m.away===teamName`
- Finished: score + result badge (W/D/L)
- Upcoming: date, time, opponent, venue
- Sorted by date

**📰 Team News Card**
- WebSearch: `"[teamName] 世界杯 2026 最新消息"`
- Top 3 results as cards: headline + snippet
- Click to expand → full text copy (WebFetch)
- In Chinese

### 4. Data Storage
- `profiles.main_team`: TEXT, nullable
