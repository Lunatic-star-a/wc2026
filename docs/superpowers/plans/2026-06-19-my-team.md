# My Team Feature — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "My Team" subscription feature: team picker modal after login, dedicated team page with AI analysis, player info, schedule, and news.

**Architecture:** Single-file changes to `worldcuppro.html`. Team page as modal overlay using existing `.modal-overlay` + `.team-modal` pattern. WebSearch for Chinese player names and team news. DeepSeek AI analysis as placeholder framework.

**Tech Stack:** Vanilla HTML/CSS/JS, Supabase (profiles.main_team), WebSearch API, ESPN data (no longer translated)

**Key design decisions:**
- Team picker appears post-login if `profiles.main_team` is null; skippable
- Nav element `navMyTeam` changes context based on state: hidden → picker trigger → team page link
- AI analysis starts as static data-driven text; DeepSeek integration point clearly marked
- Player table reuses TEAM_INFO player arrays, translated via WebSearch
- News fetched live via WebSearch, click-to-expand with WebFetch detail

function filterTeamPicker(){

function generateStaticAnalysis(teamName,info){

var _cnNameCache={};
async function getPlayerCNNames(players){
  // Try WebSearch for Chinese player names
  var result={};
  var toSearch=[];
  for(var i=0;i<players.length;i++){
    var p=players[i];
    if(_cnNameCache[p.n]){result[p.n]=_cnNameCache[p.n];continue;}
    toSearch.push(p);
  }
  if(toSearch.length===0)return result;
  
  // Search in batches of 10
  for(var bi=0;bi<Math.min(toSearch.length,5);bi++){
    var p=toSearch[bi];
